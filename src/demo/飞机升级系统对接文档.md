## 0.1 资源加密已破解（GaMe / TEA）

`assets/**` 里几乎所有图片/纹理都被自定义加密（文件头是 `GaMe` 而非 `‰PNG`）。加密算法已从
`libcocos2dcpp.so` 反汇编还原，可离线全量解密：

- **结构**：`"GaMe"`(4字节) + `flag`(1字节) + 密文；密文按 **8字节分组**。
- **算法**：**TEA**，16 轮，`delta=0x9E3779B9`，块小端。
- **密钥**：`46E330EAFAF5C3E09D4A95835704AD7C` 十六进制解码为 **16 字节**，按小端拆成 4 个 uint32 作为 TEA key。
- **工具**：`web/src/demo/decrypt_all.py`
  - `python decrypt_all.py membericon` 解某个子目录
  - `python decrypt_all.py` 解整个 assets → 输出到 `assets_dec/`（结构一致）
- 已验证：`membericon` 53 张、`itemicon` 819 张全部解出合法 PNG。飞机图标即 `membericon/{IconID}.png`。

> 生成器 `gen_plane_html.cjs` 内含等价的 JS 版 TEA 解密，直接把真实图标解密后内嵌进验证页。

## 2. `.tbl` 文件格式 + 解析器

每个 `.tbl` 是 UTF-8 制表符（`\t`）分隔，固定前 3 行表头：

```
第1行：中文列名（人看的）
第2行：英文字段名（程序用 key）  ← 用这一行做 JSON 的 key
第3行：字段类型（uint16 / string / vector<...> 等）
第4行起：数据
```

嵌套值的分隔约定：
- `vector<A,B>` 一项内用 `;` 分隔 K/V，多项之间用 `|` 分隔。
  例：属性 `1;650|3;130|4;130` = `{生命:650, 攻击:130, 防御:130}`（PropID 见第 6 节）。
- 纯 vector（如技能上限 `20|20|20|20`）用 `|` 分隔。

**通用解析器（Node/浏览器均可）**：

```js
// 把一个 .tbl 文本解析成对象数组，key 取第2行字段名
function parseTbl(text) {
  const lines = text.replace(/\r/g, '').split('\n').filter(l => l.length)
  const keys = lines[1].split('\t')          // 第2行=字段名
  const rows = lines.slice(3)                 // 第4行起=数据
  return rows.map(line => {
    const cells = line.split('\t')
    const o = {}
    keys.forEach((k, i) => { o[k] = cells[i] ?? '' })
    return o
  })
}

// 把 "1;650|3;130|4;130" 解析成 { 1:650, 3:130, 4:130 }
function parseKV(s) {
  const o = {}
  if (!s) return o
  for (const seg of s.split('|')) {
    const [k, v] = seg.split(';')
    if (k !== undefined) o[Number(k)] = Number(v)
  }
  return o
}
```

建议 AI 落地时：**离线跑一次把用到的表转成 `planeData.json` 打进 demo**，运行时不再读 tbl。

## 4. 升级维度总览（核心！飞机怎么变强）

飞机最终属性 = 下面**多个来源相加**，再乘 `member.tbl` 的系数：

```
最终属性(某PropID) = (等级属性 + 品质属性 + 星级属性 + 装备/专精/皮肤属性...) 
战斗力 = f(总属性, CombatCoe)   // 原游戏有专门公式，demo 可简化为 总属性加权和
```

养成主线：**碎片激活 → 吃经验+金币升级(Level) → 攒碎片突破品质(Quality) → 材料升星(Star) → 装备/专精/皮肤叠加**。

前期 demo **建议只做前 3 个维度**（等级 / 品质 / 星级），装备等作为可选扩展。

## 7. 建议的运行时数据结构（转好的 JSON）

AI 离线把 tbl 转成如下 `planeData.json`，打进 demo：

```json
{
  "planes": [
    { "id": 710, "name": "曙光", "elem": 2, "star": 2, "propCoe": 0.35,
      "icon": "membericon/710.png", "model": "z_hongsexiaofeiji",
      "starTrack": 1000, "activate": { "pieceId": 710, "pieceNum": 10, "gold": 0, "diamond": 0 } }
  ],
  "levelCurve": [
    { "lv": 1, "prop": { "1": 15, "3": 3, "4": 3 }, "needExp": 100, "gold": 0, "combat": 800 }
  ],
  "quality": {
    "710": [
      { "q": 100, "name": "初级", "prop": { "1": 85, "3": 17, "4": 17 }, "gold": 5000, "pieceId": 710, "pieceNum": 10, "needLv": 1 }
    ]
  },
  "star": {
    "1000": [
      { "s": 0, "item1": { "1": 20000 }, "item2": { "37000": 100 }, "prop": { "1": 0, "3": 0, "4": 0 } }
    ]
  },
  "qualityCap": [
    { "range": [100, 104], "cap": { "1": 1000, "3": 200, "4": 200 } }
  ]
}
```

**最终属性合成函数**（放进 demo）：

```js
function computePlaneStats(save, data) {
  // save: { planeId, level, quality, star }
  const acc = { 1: 0, 3: 0, 4: 0 } // 生命/攻击/防御
  const add = (kv) => { for (const k in kv) acc[k] = (acc[k] || 0) + kv[k] }

  add(data.levelCurve.find(r => r.lv === save.level).prop)
  add(data.quality[save.planeId].find(r => r.q === save.quality).prop)
  const track = data.planes.find(p => p.id === save.planeId).starTrack
  add(data.star[track].find(r => r.s === save.star).prop)

  // 品质段上限裁剪
  const cap = data.qualityCap.find(c => save.quality >= c.range[0] && save.quality <= c.range[1])
  if (cap) for (const k in cap.cap) acc[k] = Math.min(acc[k], cap.cap[k])

  return acc // { 生命, 攻击, 防御 }
}
```

## 8. 对接 `airCombat.js` 的落地清单

现状：`airCombat.js` 里玩家是 `const player = { hp, maxHp, weapon, weaponLv, ... }`（约 1782 行），
机身贴图靠 `makePlaneSprite(texture)`；已有一套“5 段进化 `EVOLVE`”是**局内**成长，与本养成系统不冲突。

改造步骤（给 AI）：

1. **加载资源**：把 `assets/membericon/*.png` 拷进 demo 的 assets 目录，用现有 `loadBase()`/`PIXI.Texture.from()` 加载；机型贴图从图标或转好的机身帧取。
2. **引入数据**：生成并 `import planeData.json`（第 2 节解析器离线转）。
3. **玩家存档**：新增局外存档 `save = { planeId, level, quality, star, exp, gold, diamond, pieces:{} }`，`localStorage` 持久化。
4. **属性接入**：局外用 `computePlaneStats(save, data)` 得到 `{生命,攻击,防御}`，映射到 `player.maxHp = 生命/…`、子弹伤害用 `攻击`、受击减伤用 `防御`。（demo 可自定映射比例，别照搬手游绝对值，否则数值过大。）
5. **升级 UI**（局外面板，非局内）：
   - 升级(Level)：花经验/金币，读 `levelCurve`，受 `SkillLimit`/品质门槛约束。
   - 突破(Quality)：花金币 + 碎片，校验 `needLv`。
   - 升星(Star)：花材料，读 `star[starTrack]`。
   - 换机：从 `planes` 列表选，切换 `player.spr` 贴图为对应图标/模型。
6. **换飞机贴图**：`player.spr.texture = PIXI.Texture.from('membericon/'+plane.icon)`。
7. **战斗力**：显示 `combat`（取表或用总属性加权）。

**验收**：能选飞机→升级/突破/升星→属性变化实时反映到局内 HP/伤害；刷新后存档保留；飞机贴图正确显示。

## 附：命名与坑

- `.tbl` 是 **UTF-8 无 BOM、`\t` 分隔、`\r\n` 换行**，解析先 `replace(/\r/g,'')`。
- 属性值里空字符串代表“无”，`parseKV` 已处理。
- `ElemType` 99/100 是宝宝/僚机，**不是玩家可玩战机**，建表时过滤。
- `member.tbl` 的 `MaxCombat` 有的行相同（占位），以实际 `CombatPoint` 曲线为准。
- 手游数值是绝对值（生命上万），**demo 里务必按比例缩放**，否则平衡崩掉。

# 骨骼动画对接（风暴雷神 + 挂载 L_15）

> 目标：把 **风暴雷神**(战机) 和 **挂载 L_15**(僚机) 两个真实骨骼动画接入项目（如 `airCombat.js`，PIXI.js）。
> 图集已 TEA 解密并内嵌，运行时纯 canvas 2D，无第三方依赖。

## 1. 需要的两个文件（直接拷进项目）

| 文件 | 作用 |
|---|---|
| `web/src/demo/skeleton_player.js` | 渲染运行时（ES module，导出 `SkeletonPlayer` 类）。支持 CocoStudio 与 DragonBones 两种骨骼。 |
| `web/src/demo/skeleton_models.json` | 两个模型的解析数据（骨骼+动画+**内嵌解密图集base64**），约 0.9MB。 |

> 数据是用 `gen_bundle.cjs`（`node gen_bundle.cjs`）从反编译资源里解密+解析生成的。要加别的战机/挂载，改 `gen_bundle.cjs` 末尾的 `buildDB('模型名')` / `buildCS('模型名')` 再重跑即可（模型名见 `member.tbl` 的 `Model` 列 / `guazai.tbl` 的 `Model` 列）。

## 2. 两个模型的 key 与动画名

`skeleton_models.json` 结构：`{ fengbaoleishen: {...}, guazai_L15: {...} }`

| 模型 | JSON key | 类型 | 可用动画 |
|---|---|---|---|
| 风暴雷神(战机1910) | `fengbaoleishen` | DragonBones | `putong`(常态) `daiji`(待机) `bianxing_1`(变形) `BaoZou_Start`→`BaoZou`→`BaoZou_End`(爆走 起/循环/收) |
| 挂载 L_15(僚机) | `guazai_L15` | CocoStudio | `Normal`(常态) `xiaohuo`(开火) `BaoZou_Start`→`BaoZou`→`BaoZou_End`(爆走) |

## 3. API（`SkeletonPlayer`）

```js
import { SkeletonPlayer } from './skeleton_player.js'

const player = new SkeletonPlayer(modelData, {
  width: 480, height: 600, // 内部画布尺寸
  fps: 30,                 // 动画播放帧率
  scale: 1.0,              // 缩放
  bloom: true,             // 能量层柔和辉光(建议开)
})
await player.load()             // 加载内嵌图集(异步一次)
player.animations()             // -> ['putong','daiji',...]
player.setAnimation('BaoZou')   // 切换动画
player.setScale(1.2); player.setBloom(false)

// 每帧调用：把当前动画在 timeSec(秒) 时刻画到 player.canvas
player.render(performance.now() / 1000)
// player.canvas 是一个 HTMLCanvasElement，可直接当贴图源 / drawImage 源
```

要点：模型**朝上**（机头向上）；`player.canvas` 每帧被重绘，尺寸固定 `width×height`；循环动画自动按时长循环（`BaoZou_Start/End` 是一次性起手/收尾，`BaoZou` 是循环段）。

## 4. 最简用法（独立 canvas，先跑通验证）

```html
<canvas id="view" width="480" height="600"></canvas>
<script type="module">
import { SkeletonPlayer } from './skeleton_player.js'
const DB = await fetch('./skeleton_models.json').then(r => r.json())
const player = new SkeletonPlayer(DB.fengbaoleishen, { width:480, height:600, fps:30 })
await player.load()
player.setAnimation('BaoZou')
const dst = document.getElementById('view').getContext('2d')
function loop(now){ player.render(now/1000); dst.clearRect(0,0,480,600); dst.drawImage(player.canvas,0,0); requestAnimationFrame(loop) }
requestAnimationFrame(loop)
</script>
```

## 5. 接入 `airCombat.js`（PIXI.js）

思路：`player.canvas` 每帧更新 → 包成 `PIXI.Texture`，用一个 `Sprite` 显示；每帧 `texture.update()`。

```js
import { SkeletonPlayer } from './skeleton_player.js'
import modelsUrl from './skeleton_models.json'   // Vite 可直接 import；否则用 fetch

// —— 初始化（放在 main() 资源加载处）——
const MODELS = await fetch(new URL('./skeleton_models.json', import.meta.url)).then(r=>r.json())

// 玩家战机换成风暴雷神：
const hero = new SkeletonPlayer(MODELS.fengbaoleishen, { width:256, height:320, fps:30, scale:0.6 })
await hero.load(); hero.setAnimation('putong')
const heroTex = PIXI.Texture.from(hero.canvas)          // 用内部canvas建纹理
const heroSpr = new PIXI.Sprite(heroTex); heroSpr.anchor.set(0.5)
planeC.addChild(heroSpr)                                 // 加到你现有的飞机层

// 一个挂载(僚机 L_15)跟在旁边：
const wing = new SkeletonPlayer(MODELS.guazai_L15, { width:160, height:200, fps:30, scale:0.6 })
await wing.load(); wing.setAnimation('Normal')
const wingSpr = new PIXI.Sprite(PIXI.Texture.from(wing.canvas)); wingSpr.anchor.set(0.5)
planeC.addChild(wingSpr)

// —— 每帧(在你的 update/ticker 里)——
const tSec = performance.now()/1000
hero.render(tSec); heroTex.update()                      // 关键：更新纹理
heroSpr.position.set(player.x, player.y)
wing.render(tSec); wingSpr.texture.update()
wingSpr.position.set(player.x + 60, player.y + 20)       // 僚机相对机身偏移

// 开火时切爆走、平时切常态：
// hero.setAnimation(firing ? 'BaoZou' : 'putong')
```

> 若你的 PIXI 是 v5/v7，`PIXI.Texture.from(canvasEl)` 均可；每帧务必调用 `texture.update()`（或 `baseTexture.update()`）否则画面不刷新。
> 想省性能：机体不必每帧 render，可降到 20~30fps 或仅在可见时渲染。

## 6. 常见问题

- **看不到/全透明**：确认 `await player.load()` 完成后再 `render`；`skeleton_models.json` 要能被 fetch/import 到（打包进静态资源）。
- **太亮/过曝**：`setBloom(false)` 或把 `skeleton_player.js` 里 render() 的 `globalAlpha=0.4` 调低。
- **太大顶边**：调小 `scale` 或调大 `width/height`。
- **换其它战机/挂载**：编辑 `gen_bundle.cjs` 增加 `buildDB/buildCS('模型名')`，`node gen_bundle.cjs` 重新生成 json。CocoStudio 用 `buildCS`，DragonBones(herodb 里 `_ske.json`) 用 `buildDB`。
