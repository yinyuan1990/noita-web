# 敌人生命值 & 战斗数值设计（对接文档）

> 本文把原游戏（反编译真实配置表）的**敌人生命值体系**和**关卡数值曲线**整理成可直接对接的设计规范，
> 供 AI 用来重做我们 demo 的战斗数值（当前数值不平衡）。玩家侧养成数值见 `飞机升级系统对接文档.md`。
>
> 原始表：`assets/data/` 下 `battlelevelmonster.tbl` / `battlemonster.tbl` / `campaign.tbl` / `chapter.tbl` / `battleparam.tbl`。

---

## 1. 敌人生命值是怎么定出来的（数据流）

```
章节 chapter.tbl ──含──> 关卡列表 campaign.tbl ──每关有──> 缺省怪物等级 DefaultMonsterLv
                                                              │
                              battlelevelmonster.tbl[方案, 等级] <─┘ 按“怪物等级”查表
                                                              │
                        ──> 给出该等级下 6 个“怪物档位”的 生命/攻击/防御
```

- 每个**关卡**只配一个 `缺省怪物等级`（怪物Lv），关卡里所有怪按各自档位从该等级取属性。
- `battlemonster.tbl` 里单个怪的属性是**占位值**（都写成 10000），真实数值来自 `battlelevelmonster.tbl` 的“等级 × 档位”。
- 怪的**档位**由怪物类型决定（秒死怪 / 小怪 / 队长怪 / 精英怪 / BOSS / 超级BOSS）。

---

## 2. 六个怪物档位 & 固定倍率（关键设计）

同一怪物等级下，各档位生命值是**固定倍率**关系（以“小怪”为 1）：

| 档位 | 生命倍率(×小怪) | 说明 |
|---|---|---|
| 秒死怪 | **0.02** | 冲脸的杂兵，一碰就死，纯氛围 |
| 小怪 | **1** | 基准单位 |
| 队长怪 | **2** | 稍硬的普通怪 |
| 精英怪 | **7** | 小boss/精英 |
| BOSS | **30** | 关底 |
| 超级BOSS | **80** | 世界/大招boss |

> 这个 0.02 / 1 / 2 / 7 / 30 / 80 的比例在全等级段都成立（验证过），**是这套设计最核心的东西**，直接照搬即可。
> 攻击(ATK)不按同比例，各档位单独配（例：Lv1 小怪ATK15、精英39、BOSS30、超级BOSS138）。防御(DEF)前期为 0。

## 5. 伤害上限 & 碰撞（battleparam.tbl）

防“秒杀”的核心机制——**单次伤害不能超过目标最大生命的百分比**：

| 档位 | 单次伤害上限(占其最大HP) |
|---|---|
| 秒死怪 / 小怪 / 队长 / 精英 / BOSS | 100%（可被一击） |
| **超级BOSS** | **50%**（至少两下才能秒） |

其它关键系数：
- 碰撞伤害：小怪撞机 `100`、BOSS撞机 `167`（Lv1值，随等级走碰撞列）。
- Boss房“狂暴(hard)”组：进房 20s / 40s 触发增援，间隔 3000ms（`battlehardplus.tbl` 配增援阵型）。
- 远征Boss按“战力差”放大子弹/AOE百分比伤害（战力差越大，玩家吃伤越高，最高 ×3）。

## 7. 玩家侧数值（对齐用，详见另一文档）

玩家战机的“底子”来自 等级/品质/星级（`memberlevel/memberquality/memberstar`）：
- 战机 Lv1 生命15/攻击3 → Lv100 生命≈9915/攻击1983 → Lv500 生命≈21.6万/攻击4.3万。
- 品质、星级、装备、僚机(挂载)、飞弹再叠加。

⚠️ **注意**：玩家“攻击几千”对敌人“血量上亿”不是直接对砍——原游戏靠**战斗力匹配**（玩家战力≈关卡推荐战力就能打），且玩家 DPS 被暴击/多弹道/僚机/飞弹成倍放大。所以**不要拿玩家ATK直接除敌人HP**，要用第 8 节的 TTK 方式重新标定。

## 8. 移植到我们 demo 的做法（重点·照这个配）

原始绝对值是亿级放置数值，弹幕 demo 不能直接用。**保留设计骨架，重标数值**：

**① 档位倍率直接照搬**（这是精华）：
```
秒死:0.02  小怪:1  队长:2  精英:7  BOSS:30  超级BOSS:80
```

**② 用“击杀时间(TTK)”反推血量**，而不是抄绝对值：
```
玩家DPS = 单发伤害 × 每秒发数 × 平均命中弹道数 × (1+暴击收益)
小怪HP   = DPS × 目标TTK
```
建议 TTK 目标（弹幕手感）：
- 小怪 0.2~0.6s、队长 1~2s、精英 3~6s、BOSS 20~40s、超级BOSS 40~80s。
- 用 `小怪HP = DPS×0.4s` 定基准，其余档位按①的倍率乘出来。

**③ 关卡成长用平缓曲线**（别用原版每级+30%的爆炸曲线）：
```
关卡N 的小怪HP = 基准小怪HP × 1.10^(N-1)      // 每关+10%，或
关卡N 的小怪HP = 基准小怪HP × (1 + 0.15·N)     // 线性更可控
```
玩家 DPS 随养成也按相近斜率涨，保证 TTK 大致恒定（关越深不会越肉/越脆）。

**④ 伤害上限照搬**：单次伤害 ≤ 目标当前最大HP（普通档），超级BOSS ≤ 50%。防止一发秒 boss。

**⑤ 攻击/碰撞**：敌人ATK 用“占玩家最大HP的百分比”来配（如小怪撞机扣 5%、BOSS子弹扣 10~15%），比抄绝对ATK稳。

一句话：**倍率(0.02/1/2/7/30/80) + TTK 定基准 + 平缓成长 + 伤害上限**，就能复刻原版的战斗节奏而不炸数值。

### 10.2 直接对接代码（推荐：按 TTK 缩放，不用绝对值）

```js
import ENEMY from './enemy_data.json'   // Vite 可直接 import；否则 fetch

// 取某关某档位的“原始”数值（方案1）
function rawStat(stageId, tier) {
  const st = ENEMY.stages.find(s => s.id === stageId)
  const row = ENEMY.monsterLevels['1'][st.monsterLv - 1]   // 数组下标=等级-1
  return row[tier]   // {hp, atk, def}
}

// —— demo 用：只借“设计骨架”，血量用 TTK 反推（见第8节）——
const DEMO = {
  playerDPS: 120,        // 你的玩家每秒伤害(按实际武器算)
  baseTTK:   0.4,        // 小怪目标击杀秒数
  growth:    1.10,       // 每关血量增长(温和曲线)
}
// 关卡序号 stageIndex 从 1 开始；tier 用 tierRatio 的键
function enemyHP(stageIndex, tier) {
  const baseMobHP = DEMO.playerDPS * DEMO.baseTTK        // 第1关小怪基准血
  const stageMul  = Math.pow(DEMO.growth, stageIndex - 1)
  return Math.round(baseMobHP * ENEMY.tierRatio[tier] * stageMul)
}
// 例：第10关的BOSS血量
enemyHP(10, 'boss')   // = 120*0.4 * 30 * 1.10^9 ≈ 3396

// 伤害上限(照搬)：单次伤害不超过目标最大HP的百分比
function capDamage(dmg, targetMaxHP, tier) {
  return Math.min(dmg, targetMaxHP * ENEMY.damageCapPct[tier])
}

// 敌人攻击建议用“占玩家最大HP百分比”，别抄绝对ATK：
const enemyHitPct = { xiaoguai:0.05, duizhang:0.07, jingying:0.10, boss:0.13, chaojiboss:0.15 }
function enemyDamage(playerMaxHP, tier){ return Math.round(playerMaxHP * enemyHitPct[tier]) }
```

### 10.3 若要“忠实还原”原版（做数值养成向，非纯弹幕）

直接用绝对值：`hp = ENEMY.monsterLevels['1'][monsterLv-1][tier].hp`，玩家侧战力对齐关卡 `fighting`（推荐战力）。此时不需要 TTK 缩放，但注意数值是亿级，UI 要做 万/亿 缩写显示。

### 10.4 一句话选型

- **弹幕手感 demo** → 用 10.2（TTK + 倍率 + 温和成长），无视原始绝对值。
- **数值养成还原** → 用 10.3（绝对值 + 战力匹配）。
- 两种都**照搬**：`tierRatio(0.02/1/2/7/30/80)` 和 `damageCapPct(超级BOSS 0.5)`。

### 11.2 伤害怎么算

```
单发伤害 = 攻击(atk) × 弹幕百分比 k        // 普攻 k≈1，主动技能更高，可自定
DPS      = 单发伤害 × 每秒发数 × 命中弹道数 × (1 + 暴击收益)
```
我方随等级变强靠 `atk` 上涨；`k/射速/弹道` 是你武器设计参数。

### 11.3 与敌人 HP 匹配（核心：TTK 恒定）

我方等级 L 对应打第几关，自己定个映射（例：`关卡 = L` 或 `关卡 = floor(L/2)`）。目标是**任何进度下击杀时间(TTK)大致恒定**：

```
玩家DPS(L)   = playerAtk(L) × k × 射速 × 弹道          // playerAtk 见 11.1 / player_data.json
小怪HP(关卡)  = 玩家DPS × 目标TTK小怪                  // 目标TTK: 小怪0.4s
其余档位HP    = 小怪HP × 档位倍率(0.02/1/2/7/30/80)
```
只要 `玩家DPS` 和 `敌人HP` 用**相近的增长斜率**，TTK 就稳定，不会越打越肉或越脆。

**做法A（推荐·自洽）**：敌人 HP 直接由“当前玩家 DPS × 目标TTK × 档位倍率”实时算，天然匹配，不用查原表绝对值。

**做法B（用原版手感曲线）**：敌人 HP 用 `enemy_data.json` 的相对形状，但**整体除以一个系数**对齐我方 DPS：
```
系数 = 原版小怪HP(某等级) / (我方DPS × 目标TTK)
敌人HP(demo) = 原版HP / 系数
```

### 11.4 代码对接

```js
import PLAYER from './player_data.json'
// PLAYER.levels[L-1] = { lv, atk, hp, def, combat, upCost }

const cur = { level: 1 }
function playerAtk(){ return PLAYER.levels[cur.level-1].atk }
function playerHP(){  return PLAYER.levels[cur.level-1].hp }
function upCost(){    return PLAYER.levels[cur.level-1].upCost }   // 一键升级消耗
function levelUp(gold){ const c=upCost(); if(gold>=c && cur.level<PLAYER.levels.length){ cur.level++; return c; } return 0 }

// 玩家DPS(按你的武器参数)
const WEAPON = { k:1.0, fireRate:8, lanes:3, critBonus:0.3 }
function playerDPS(){ return playerAtk()*WEAPON.k*WEAPON.fireRate*WEAPON.lanes*(1+WEAPON.critBonus) }

// 敌人HP(做法A：自洽TTK) —— 配合 enemy_data.json 的 tierRatio
import ENEMY from './enemy_data.json'
const TTK_MOB = 0.4
function enemyHP(tier){ return Math.round(playerDPS()*TTK_MOB*ENEMY.tierRatio[tier]) }
// 伤害上限仍照搬：capDamage(dmg, maxHP, tier) = min(dmg, maxHP*ENEMY.damageCapPct[tier])
```

一句话：**我方 atk 照 `player_data.json` 走；敌人 HP = 玩家DPS×TTK×档位倍率**，两边自动匹配。
