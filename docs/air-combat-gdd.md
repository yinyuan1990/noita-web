# 森林空战 2.0 · 完整策划案（GDD）

> 版本 v1.0 · 2026-08-26
> 范围：10 关卡 × 10 场景 · 战机 5 段进化 · 10 Boss · 全屏技能（核弹）· 敌人扩编 · 分类爆炸音效
> 原则：全部基于现有代码架构（分块无限地图 / 编队系统 / 弹幕库 / cocos 粒子层）增量扩展，素材全部使用可商用免费授权（CC0 / CC-BY / CC-BY-SA）。

---

## 一、设计支柱

1. **一关一景一 Boss**：每关是"3 个精英波次 + Boss 战"的节奏包，场景、敌人涂装、Boss 全部服务于本关主题。
2. **成长可视化**：武器等级、机体进化、僚机浮游炮全部画在飞机上——玩家不用看 HUD 就知道自己变强了。
3. **爆炸即语言**：每种武器/每个 Boss 死亡都有专属的视觉+听觉签名，核弹是全游戏最高规格的演出。
4. **弹幕即性格**：敌人种类靠弹幕和行为区分，不靠堆血量。

## 四、Boss × 10（一关一战）

通用规则：
- Boss = 多部件实体（本体 + 2~4 个可破坏部件），部件有独立血条与弹幕，全毁进入下一阶段。
- 每 Boss 3 阶段，阶段转换有 1.5s 演出（闪白 + 咆哮音 + 弹幕清屏）。
- 血条显示在屏幕顶部；Boss 死亡 = 多段连环爆 + bigBang + 场景专属演出 + 必掉 3P + 1 核弹。

| # | Boss | 形态构成 | 三阶段弹幕摘要 | 专属机制 |
|---|---|---|---|---|
| 1 | 绿荫堡垒（巨型运输机） | 本体+左右机炮塔 | 瞄准弹→扇面弹墙→尾舱放蜂群 | 教学 Boss，弹速全场最低 |
| 2 | 沙蝎（掘地舰） | 头+尾刺+两螯 | 钻沙潜行（只露沙痕）→跃出环爆→尾刺激光扫场 | 潜行期只能打沙痕预判 |
| 3 | 冰髯（破冰巨艇） | 本体+破冰角 | 冰锥扇面→碎冰全向环→暴风雪(全屏减速 20%) | 冰锥落地留减速冰面 |
| 4 | 沼泽双蛇（双头直升机） | 两个可分离头 | 双头交叉瞄准弹→毒雾弹幕(留毒圈)→残头狂暴双倍射速 | 打掉一头另一头狂暴 |

## 五、我方战机 5 段进化（外观华丽化核心）

机体等级 = 四武器等级总和驱动，自动进化，每次进化有变身演出（闪白 + 冲击环 + 机体换装动画）：

| 阶段 | 命名 | 触发(Σ武器Lv) | 外观变化 | 数值/功能 |
|---|---|---|---|---|
| Mk-I | 隼 | 初始(4) | 现有机体 ship_0003 | 基准 |
| Mk-II | 苍鹰 | ≥10 | 翼尖挂载吊舱 ×2（子 sprite）+ 引擎焰加长 | 移速 +5%，副武器 cd -10% |
| Mk-III | 雷鸟 | ≥18 | 换机体涂装（tint 渐变蓝）+ 双引擎喷焰 + 巡航光晕 | +1 浮游炮（自动瞄准补射） |
| Mk-IV | 玄凰 | ≥27 | 换大机体 sprite + 金色描边流光（shader-free：叠加 add 光层脉动） | 浮游炮 ×2，HP 上限 +25 |
| Mk-V | 烛龙 | ≥36(满 40 前) | 全身流光 + 尾部彩虹航迹 + 机体微放大 1.15× | 浮游炮 ×2 升级为激光炮，氮气 cd -30% |

**浮游炮（Options）**：小 sprite 跟随本体呈编队漂浮（弹簧跟随算法），继承主武器的低配射击——这是"武器升级更华丽"最直接的画面增量。
**武器华丽化补充**（在现有 10 级表之上）：
- 每 3 级换弹体贴图档位（小→中→大 + 光晕层）。
- Lv10 解锁"过热特写"：开火 3s 后枪口出现持续光环 + 弹道加白热描边。
- 满级武器切换时 HUD 和机身各闪一次对应武器色的波纹。

## 六、全屏技能：核弹（B 键）

经典 shmup 保险丝设计：
- **库存制**：开局 2 枚，上限 5；Boss 必掉 1，第 4/8 波各随机掉 1（新拾取物 `N`，橙红涂装）。
- **演出时间轴**（总 2.6s，全程输入不中断）：
  1. 0.0s：投放音（气笛下坠）+ 屏幕边缘红光收缩聚焦到弹着点
  2. 0.6s：白屏闪 0.2s + 全屏震 25 + `bigBang`×1.6 + `canBlast`×1.4 双层 cocos
  3. 0.7s：三重冲击环从中心横扫全屏（半径 2200），**清除所有敌弹**（每颗敌弹原地小闪光）
  4. 0.7~1.4s：全部敌机结算 60 伤（Boss 部件 30），屏幕内敌机基本团灭
  5. 1.0s：蘑菇云——柱状浓烟拔起 + 顶部环状扩散（自研粒子编排,新 `nuke` 爆炸类）
  6. 2.6s：尘埃余烬缓落，地面留超大焦痕
- **平衡**：动画期间玩家无敌；核弹击杀不计连击（防刷分）。

## 七、爆炸音效方案（程序化生成，全部不同）

写一个 node 离线脚本 `scripts/gen-sfx.mjs`（零依赖，直接写 WAV PCM），按分类合成 9 套新音效，替换现在共用的两三个采样：

| 分类 | 合成配方 | 听感 |
|---|---|---|
| vulcanHit | 3ms 白噪爆 + 4kHz 金属谐振衰减 | 叮脆火花 |
| fire(导弹) | 噪声爆 + 低通 800→200Hz 扫频 0.4s | 标准"轰" |
| cluster | 双段：60Hz 正弦重锤 + 0.15s 后噪声爆余响 1.2s | 闷雷连响 |
| tesla | 方波 120Hz 调制噪声 0.2s + 高频嘶声 | 电弧炸裂 |
| aurora | 钟形正弦 880/1320Hz 双音 + 噪声垫 | 清亮空灵 |
| flak | 短噪声爆 + 300Hz 共振 0.25s | 闷响炮团 |
| groundBoom | 噪声爆 + 90Hz 尾 + 碎屑颗粒声(短噪声簇×6) | 土石崩落 |
| nuke | 0.3s 静默→次声 40Hz 巨浪 2.5s + 白噪风啸尾 | 灭世 |
| bossDie | cluster 配方 ×3 错峰 + 金属撕裂谐振 | 连环殉爆 |

每类仍走现有 `playSfx` 的随机音调抖动（±15%），同类连响不重复感。
