## Noita 地图四层创作栈(2026-08 调研结论,依此开刀)

Noita 的"开放世界感"不是「没有人工干预」,是四层手工创作+程序填充的堆叠。人工发生在做游戏时,每局运行零画家:
1. **宏观 biome_map.png**:70×48 手绘小图,1px=512×512 区块,纵向主线(矿坑→煤矿→雪窟→基地→丛林→宝库→神殿)+横向支线(雪原/沙漠/真菌洞/熔岩湖),层间插圣山休息室。**宏观拓扑是设计师手画的,算法只填充区域内部**
2. **群系 biome.xml**:每区绑材质表(瓦片灰阶→本群系材质,同瓦片异群系长出异材质)/专属 wang 瓦片集/Lua 脚本/背景/植被/**群系修饰符**(潮湿/炎热/黑暗,按种子随机附加,进区弹横幅)
3. **中观 Pixel Scenes**:手绘布景池(material/visual/background 三图层),每群系垂直+水平两池带权重,`color_material` 随机化(桶里随机填油/酒精/火药);全局固定布景按绝对坐标
4. **微观标记像素**:瓦片里画标记色像素→入世时回调 wang_scripts.csv 注册的 spawn 函数(敌人/道具/灯/法杖台/宝珠),Lua 概率表二次随机。**位置是画的,出什么是随机的**

## 2. 地图模块(本次重做,对标结论)

**Noita 官方方案**(GDC 2019 + 逆向证实):
1. [Herringbone Wang Tiles](https://github.com/nothings/stb/blob/master/stb_herringbone_wang_tile.h)(Purho 直接用了 Sean Barrett 的 stbhw 库):手绘 PNG 瓦片模板,边缘颜色约束,人字形拼接消除网格感
2. 瓦片里的特殊像素 = 敌人/道具生成点(spawn pixels)
3. 生成后跑**连通性检查**(pathability),不通就 reroll
4. 手工「像素场景」(pixel scenes)按概率戳进世界(神庙、实验室)
5. 游戏级精确开源参考:[noita-worldgen](https://github.com/vitaminmoo/noita-tools)(Rust/MIT,逐字节复刻,wasm 友好)

**我们现在怎么做**(已对齐原作流程,不是「零人工」):
- 形状层=真 coalmine 手绘砖 144 块,Herringbone 拼,算法不改形状
- 内容层=P1 分区脉络 / P2 砖内标记掷骰 / P3 布景盖章 / P4 局修饰符
- 地表仍独立闭式生成(大起伏+中景树),Noita 地表也不是 wang
- ASCII / 程序雕洞只当 HB 资产缺失的回退

细节与铁律见 `pixel-guide.md` §0 §3.1。下一刀是 P6 内容 pass,不是再发明一套雕洞。

### 商业级地图路线图(差距拆解,按序执行)

现状与商业品质的差距本质是:**我们的地图是"代码生成的",商业地图是"美术设计+算法拼装的"**。追平的路径:

- **阶段 A ✅(2026-08)地表自然化**:多八度余弦插值噪声地形(150/55/22px 三波长,群系高度偏置平滑过渡)替代随机游走;土壤分层(草皮 M_MOSS→泥土 M_DIRT→基岩,冰川=冰盖),每列深度确定性哈希
- **阶段 B ✅(2026-08)资产管线(商业化的分水岭)**:地图块 = **PNG 模板** `public/res/pixel-tiles/tileset.png`(10 块 48×40,颜色→材质映射+火把标记,详见 `docs/pixel-guide.md` §3);生成器 `scripts/gen-pixel-tiles.mjs`;加载失败回退 ASCII;连通性 85%。从此地图质量取决于"画得多好"而非"代码多巧"
- **阶段 C ✅(2026-08)真 Herringbone Wang**:移植 stbhw 边缘色算法(`hbGenerate/hbChoose`,人字形错缝+边缘颜色约束),方格缝彻底消失;砖资产=64 边色组合×2 变体双条带(`tileset-hb-h/v.png`,gen 脚本生成),边色运行时从像素推导(重画零配置);flood-fill 校验 <80% 自动 reroll+救援竖井保底(Noita 同款)。细节见 `docs/pixel-guide.md` §3.1
- **阶段 D 像素场景戳 + 装饰规则**:手绘 setpiece(神庙/实验室/宝库)按稀有度盖章;自动装饰规则(地形顶边挂草/底边挂藤/转角描边/悬空滴水)
- **阶段 E 垂直群系栈**:世界改为纵向多层群系(地表→矿坑→雪窟→熔岩城),层间"圣山"休息站(商店/perk),对齐 Noita 的一局节奏

判断标准:阶段 B 完成后,地图的上限就不再是工程问题——这是"从长计议"的关键一步,建议下一个大版本就做。

## 10.5 Noita 细节对照清单(2026-08 wiki 挖矿成果)

来源:[Materials](https://noita.wiki.gg/wiki/Materials) / [Status Effects](https://noita.wiki.gg/wiki/Status_Effects) / [Wands](https://noita.wiki.gg/wiki/Wands) / [Advanced Wand Mechanics](https://noita.fandom.com/wiki/Advanced_Guide_To_Wand_Mechanics)

**① 染色系统 Stains(缺口最大,优先级最高)**——实体沾液体获得涂层状态,独立于材质模拟:
- 湿 Wet:防点燃;但电击伤害更高(湿身无电击无敌帧)
- 油 Oiled:地面打滑(会滑下坡)、着火烧更久、可穿更窄缝隙
- 血 Bloody:防点燃 + 暴击率提升
- 毒泥 Toxic:持续伤害,跳水可洗掉
- 反直觉神细节:**已着火跳进油里=灭火**(火需要空气)✅已落地;湿/血+油双染色=进火即燃出火即灭
- 我们的 elem-demo 已验证过实体涂层玩法,平移进 pixel-demo 即可

**② 材质细节**
- 密度分层:油浮于一切液体 ✅已有
- 每种液体三态:可流动/可装瓶(药瓶)/可喝(喝油=食物中毒)→ M2 药瓶系统
- 冻结变体:冻血/冻毒/冻油(火烤还原)→ 冰做成"任何液体的冻结形态"
- 血 + 岩浆 = 火山岩(血也能凝固熔岩,不只水)
- 炼金反应表(速率制):Lava+Oil→Lava+Fire(速率8)等,材质对撞有全局配方表
- 机器人流油、人形流血 ✅已落地(战机残骸现在可点燃)

**③ 电系统(我们完全没有)**
- 电流沿导电材质与液体传导:电击水池 = 全池带电,池中所有生物触电
- 持电法杖浸入液体 ≈3 秒后持续放电
- 湿身受电无无敌帧;Stunned 麻痹
- 落地方案:M_WATER/M_BLOOD 导电,电载荷命中液体 → flood 传导数帧,池内实体全部麻痹+伤害

**④ 法杖细节(M2 的设计规格)**
- 三参数:施法延迟 Cast Delay(块间冷却)/ 装填 Recharge(整轮打完的冷却,二者并行不叠加)/ 法力 Mana+回复速度
- 施法块 Casting Block:多重施法把连续 N 张卡打包成一块;块内所有卡的 ±延迟求和
- **触发卡从触发器施放时完全无视施法延迟**——rapid 构筑的核心漏洞(=乐趣)
- 60fps = 每帧最多一次施法是全游戏射速上限;链锯等负延迟卡可把延迟堆到 0
- 法杖分洗牌/不洗牌;最多带 4 根
- Add Mana 修正卡可让法术倒赚法力(构筑深度的例子)
