Combat SFX (skill FX accompanying attribute)
============================================

Real CC0 ogg files (preferred):
  wind.ogg  rain.ogg  thunder.ogg  electric.ogg
  water.ogg fire.ogg  explosion.ogg
  impact.ogg magic.ogg clash.ogg

SoundSystem loads .ogg first, then .mp3 / .wav.
If missing, falls back to WebAudio synth.
